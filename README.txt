МАНЖИЙН ЭРХШЭЭЛИЙН ҮЕИЙН МОНГОЛ

index.html файлыг браузераар нээнэ. Суулгалт, сервер, интернэт шаардлагагүй.

Шинэ загвар: 23 хэсэгтэй, хар хөх дэвсгэр, зэс акцент, текстэн
агуулга, он цагийн шугам, захиргааны бүтэц, хөдөлгөөнт шилжилттэй.
Дээд Агуулга цэсээр бүх хуудас руу очно. Доод цэс, суман товч,
PageUp/PageDown, Home/End ашиглаж болно. Бүтэн дэлгэцийн товчоор дүүрэн горимд орж, дахин дарж буцна.
Системийн хөдөлгөөнийг багасгах тохиргоог хүндэтгэнэ.

Эх бичвэр товчоор тухайн хуудасны эх текстийг бүтнээр нь уншина.
content.json, pages.js дахь эх бичвэрийг өөрчлөөгүй. Эх материалд
байсан үсгийн алдаа, давхардлыг эх бичвэрийн цонхонд хадгалсан.
Эх PDF assets/mongolia-source.pdf файлд хадгалагдсан.
